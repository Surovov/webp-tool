# В WebP

Переводит картинки (PNG, JPG, BMP) в WebP — формат, который весит в разы меньше при том же виде. Сделано для карт и жетонов Roll20, но годится для любых картинок.

Пример: карта 3072×2048, PNG 9,9 МБ → WebP 1,4 МБ. Прозрачный фон у жетонов сохраняется.

Есть три способа, выбирай любой.

## 1. Страница в браузере — ничего не ставить

Открой **https://surovov.github.io/webp-tool/**

1. Перетащи картинки на страницу (или нажми и выбери; можно вставить из буфера через Ctrl+V).
2. Выбери, что сделать с размером:
   - **Не менять** — только формат;
   - **Жетон 256** / **Жетон 512** — ужать по длинной стороне;
   - **Карта по клеткам** — вводишь, сколько клеток по ширине и высоте, получаешь картинку ровно под сетку (в Roll20 клетка — 70 точек);
   - **Своя длинная сторона** — любое число.
3. Скачай файлы по одному или кнопкой «Скачать всё одним архивом».

Картинки никуда не отправляются: всё считается в твоём браузере. Страница работает и без интернета — скачай `index.html` и открой двойным щелчком.

Нужен Chrome, Edge или Firefox. Safari сохранять WebP не умеет — страница об этом скажет.

## 2. Командная строка — когда картинок много

Нужен [Python](https://www.python.org/downloads/) (на Windows при установке поставь галочку «Add Python to PATH»).

```
git clone https://github.com/Surovov/webp-tool
cd webp-tool
pip install pillow
```

Дальше:

```
python to_webp.py "путь к папке"                    все картинки папки, размер как был
python to_webp.py "путь к папке" --max 256          жетоны: ужать до 256 по длинной стороне
python to_webp.py карта.png --cells 42x28           карта под сетку 42×28 клеток по 70 точек
python to_webp.py "путь к папке" -r -o готово       с подпапками, результат в папку «готово»
```

Готовые файлы появляются в подпапке `webp` рядом с исходниками (или там, где скажешь через `-o`). Исходники не меняются и не удаляются.

Все настройки:

| Ключ | Что делает |
|---|---|
| `--max N` | ужать до N точек по длинной стороне; маленькие не увеличиваются |
| `--size ШxВ` | точный размер, например `2940x1960` |
| `--cells КxР` | карта под сетку: клеток по ширине × по высоте |
| `--px N` | точек на клетку для `--cells` (по умолчанию 70) |
| `-q N` | качество 1–100 (по умолчанию 90) |
| `--lossless` | без потерь — для пиксель-арта и чертежей, файл больше |
| `-o ПАПКА` | куда класть результат |
| `-r` | заходить в подпапки |
| `--overwrite` | перезаписывать уже готовые файлы (по умолчанию пропускаются) |

## 3. Через ИИ-помощника

Если у тебя есть помощник, который сам запускает команды на компьютере (Claude Code, Gemini CLI и подобные), скажи ему:

> Склонируй https://github.com/Surovov/webp-tool, прочитай AGENTS.md и переведи в WebP все картинки из папки «…». Исходники не трогай.

Что и как запускать, помощник прочитает в [AGENTS.md](AGENTS.md).

## Памятка для Roll20

- Карта: 70 точек на клетку, без нарисованной сетки (Roll20 кладёт свою), качество 90.
- Жетон человека: 256×256. Крупная техника и большие монстры: 512×512. Фон прозрачный.

---

**In English.** Converts PNG/JPG/BMP images to WebP. Use the [web page](https://surovov.github.io/webp-tool/) (runs entirely in your browser, nothing is uploaded) or the command line: `pip install pillow`, then `python to_webp.py <folder> [--max 256 | --size WxH | --cells COLSxROWS] [-q 90] [-o OUT] [-r]`.
